# Device notes

Open the app from the launcher, choose a clue, write an answer, then check and reveal a clue. Add a standard,
unlocked crossword to the Kindle's documents folder and open it through the puzzle list. Confirm the current game
survives sleep and reopening. Return using Done before exercising Store removal.

"By the water" and "At the desk" are original puzzles by Primitive AI. Both are covered by the repository's CC BY-NC-SA
4.0 documentation licence in `LICENSE-DOCS`. The importer follows the community format description maintained by
[puzpy](https://github.com/alexdej/puzpy/blob/master/FileFormat.md). It handles standard single-letter cells with unlocked
solutions.
